# 注意事項と精度確認

## 対応する解析

閉じた有限領域の静的・微小変形・線形等方弾性を扱います。複数材料は領域を分け、節点が一致する完全接合で連結します。2Dは平面ひずみ／平面応力、3Dは三次元弾性です。

現在のExcel入力はRECT/CIRCLE/POLYGONとBOX/SPHERE、境界グループ内で一定の成分別条件です。任意CAD面、穴を持つ複数輪郭、非一致メッシュの接合、接触・すべり・剥離、塑性、大変形、異方性、動的解析、無限／半無限領域、体積力・温度荷重の入力には対応していません。添付元Pythonで表現できる任意メッシュや場節点ごとの境界値が、すべてExcel入力表から設定できるわけではありません。

## 単位

長さ・変位はm、E・応力・表面力はkPaに統一します。例えばE=30 GPaは30000000 kPaです。mm座標をそのまま入力するとmとして扱われます。

3Dの表面力積分の合力はkNです。2Dの線積分による合力は奥行き単位長さ当たりのkN/mです。実際の厚さによる全荷重へ換算する場合は厚さ[m]を掛けます。2Dの平面状態は、単純な厚さ倍率とは別の仮定です。

## 「収束OK」で確認される範囲

この表示は線形方程式の真の相対残差と、要求した内部場の数値積分判定が通ったことを示します。境界の離散化、曲面の近似、FMM遠方展開の誤差を自動的に保証する表示ではありません。FMMの残差はFMMで近似した演算子に対する残差です。

次の順で対象モデルの精度を確認します。

1. 小さいモデルでdenseとFMMを比較し、変位・表面力・内点応力の差を確認します。
2. FMMのpを上げ、必要ならthetaを下げて、注目値の変化を確認します。pの増加は3Dで特に時間・メモリを増やします。
3. 分割を細かくし、同じ物理位置の変位・応力、合力、反力を比較します。定数／二次要素でも比較できます。
4. 境界近傍では内点積分の許容差、最大レベル、評価点数上限を調整し、report.jsonの推定誤差と打切り理由を確認します。

角部・荷重や拘束の切替位置では応力が強く変化し、特異となる場合があります。要素端に近い値やVTKの節点補間値を、そのまま収束した最大応力と扱わないでください。

## 未達・取得不可・入力変更

| 表示・記録 | 意味と対応 |
|---|---|
| LINEAR_SOLVE_TOLERANCE_UNMET | GMRESが反復上限で停止。現在の近似解を保存。拘束、メッシュ、材料差、p、restart、反復上限を確認 |
| QUADRATURE_TOLERANCE_UNMET | 内点積分の精細化が許容差に未達。最後の有限値を保存。許容差と評価点数・レベル上限を確認 |
| value_available=False / 取得不可 | 境界に近すぎる、または必要な積分値を取得できない。CSV/NPZのNaNを0に置換して解釈しない |
| 旧入力の結果・再解析が必要 | 画面の値は変更前の入力による結果。再解析する |
| 原点をモデルの近くに移してください | 原点／モデル寸法の比が入力上限1E8を超過。モデルと評価点を同じ量だけ移動する |
| メモリ上限超過 | 分割、p、キャッシュ、GMRES restartを見直す |

内点は指定領域の内部に置きます。境界上の評価や境界面を越えてすぐ外側の評価は対象外です。B61以下の距離比の点は取得不可となります。Escで解析を中断できます。

## 大座標と数値精度

2026-10-09のissue #1修正では、面積判定と積分・FMMを領域の局所座標で計算し、出力座標は入力の絶対座標へ戻しています。JSON/CSV/VTKは、Double値を往復できる精度で数値を保存します。

ただしExcelへの数値入力や絶対座標の幾何節点生成で既に失った桁は復元できません。たとえば1E8 m付近のDoubleの隣接値間隔は約1.49E−8 mです。その尺度に近い微小寸法・細かい曲面・評価点距離を与える場合は、モデルと評価点の原点を近くへ移動してください。入力を許可する上限と、要求精度を達成できる範囲は一致しません。[修正と検証](issue-1.md)に具体例を記録しています。

## 実行環境・計算規模

Windows版デスクトップExcel向けです。Excel OnlineではVBA解析を実行できません。Mac版Excelは本ブックのWindows API・COM機能の検証対象外です。VBAソースはVBA7向けPtrSafe宣言と旧VBA向け宣言を持ちますが、今回の数値検証はWindows上のExcel 16.0で実施しています。

FMMは全体G/H密行列を作りませんが、近傍ブロック、木、展開、キャッシュ、GMRES作業配列の記憶量が必要です。autoの時間・メモリ推定は実行時の環境に依存します。B57の未知数上限まで常に実用的な時間・メモリで計算できる保証はありません。細長い形状、密集したメッシュ、高いp、材料差の大きい接合では負荷が変わります。

通常利用はマクロの有効化だけで動作します。Python検証やソース再組込みを行う開発時だけ「VBAプロジェクト オブジェクト モデルへのアクセスを信頼する」が必要です。計算途中や出力先不足による中断時には、完了したreport.jsonとその判定を確認して結果を扱ってください。
