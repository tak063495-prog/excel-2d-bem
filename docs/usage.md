# 使い方と2D / 3Dの入力

対象はWindows版デスクトップExcelです。解析・オートメッシュ・FMM・GMRES・ファイル出力は、配布xlsmに組み込んだVBAで実行します。通常利用にPythonのインストールは不要です。

## 最初の解析

1. [組込済みxlsm](../outputs/bem_vba_stage3/Elastic_BEM_VBA_Full.xlsm)をダウンロードし、書込み可能なフォルダへ保存します。GitHubのファイル画面では「Download raw file」を使用してください。[ZIP一式](../outputs/Elastic_BEM_VBA_Stage3.zip)からの展開でも利用できます。
2. Excelで開き、マクロを有効にします。インターネット由来のマクロがブロックされた場合は、配布元を確認したうえでExcelを閉じ、対象ファイルのWindows「プロパティ」で「許可する」を選択して開き直します。組織のポリシーで禁止されている場合は管理者の設定に従います。[Microsoftの説明](https://learn.microsoft.com/en-us/microsoft-365-apps/security/internet-macros-blocked)
3. 初期モデルをそのまま「メッシュ生成」→「VBA解析実行」で計算します。
4. 「内点結果」で中央の応力を確認します。初期モデルは平面ひずみの1 m四方、E=30000 kPa、ν=0.3、右辺のtx=100 kPaです。中央で概ねσxx=100、σyy=0、σzz=30 kPaとなります。
5. 「JSON・CSV出力」で保存します。既定先はブックのフォルダの`model_output/bem_model/`です。

初期モデルは二次要素・各辺16分割、64境界要素、192場節点、384未知数です。FMMによる解析結果を保存してあります。独自モデルを作る前に、別名のxlsmへ保存すると入力例を残せます。

## 次元は「操作」B5で一括指定

| 設定 | 2D | 3D |
|---|---|---|
| B5 | `2D` | `3D` |
| B6 | `plane_strain`または`plane_stress` | 三次元状態を自動使用 |
| 使用座標 | X・Y | X・Y・Z |
| 境界成分 | ux/uy、tx/ty | ux/uy/uz、tx/ty/tz |
| 形状 | RECT / CIRCLE / POLYGON | BOX / SPHERE |
| 境界要素 | 線分 | 三角形 |

B7は全領域共通で、`0`=定数場、`2`=不連続二次場です。1つのモデルに2Dと3Dを混在させません。2DではZ関連セルを使用せず、3Dへの切替時に3成分目を入力します。次元切替は既存の入力を消去しないため、形状・境界名・評価点・境界条件を合わせて変更します。

平面ひずみは奥行方向のひずみを0とするモデル、平面応力は奥行方向の応力を0とするモデルです。どちらを使うかは解析対象の形状と荷重で判断します。[計算上の意味](bem-principles.md#2dの平面状態)も参照してください。

## 入力表

表の見出しは5行目、データは6行目からです。途中の空行に依存せずIDで関連付けます。IDはASCII英数字・`_`・`-`を使い、領域ID・材料IDを重複させません。

| シート | 列と入力内容 |
|---|---|
| 材料 | A:材料ID、B:E[kPa]、C:ν。E>0、−1<ν<0.5 |
| 領域 | A:領域ID、B:形状、C:材料ID、D/E/F:原点X/Y/Z[m]、G/H/I:寸法X/Y/Z[m]、J:半径[m]、K/L/M:分割数 |
| 輪郭2D | A:領域ID、B:頂点順番1から連番、C/D:X/Yの絶対座標[m]。POLYGONで使用 |
| 境界条件 | A:領域ID、B:境界名、C/D:X成分の種類と値、E/F:Y成分、G/H:Z成分 |
| 接合 | A/B:領域Aと境界A、C/D:領域Bと境界B |
| 評価点 | A:領域ID、B:点ID、C/D/E:X/Y/Zの絶対座標[m] |

RECT/BOXの原点は最小座標の角、CIRCLE/SPHEREは中心です。POLYGONでは「領域」の原点欄を使用せず、「輪郭2D」の絶対座標から範囲を求めます。POLYGONの最初の頂点を末尾に重ねて入力しません。時計回りに入力した多角形は生成時に反転し、外向き法線を持つ輪郭にします。自己交差・重複・折返しはエラーです。

## オートメッシュと境界名

「操作」B8は代表要素長さh[m]、B9は生成要素数の上限です。領域の正の分割数を優先し、未指定方向をhから決定します。RECT/BOXは各軸、CIRCLEは周方向、SPHEREはK=経度・L=緯度です。POLYGONのKを指定すると各辺を同数に分割し、未指定なら辺長/hから分割します。

| 形状 | 境界名 |
|---|---|
| RECT | BOTTOM / RIGHT / TOP / LEFT |
| CIRCLE・SPHERE | OUTER |
| POLYGON | EDGE1、EDGE2…（入力頂点の辺順） |
| BOX | XMIN / XMAX / YMIN / YMAX / ZMIN / ZMAX |

円は8分割以上、球は経度8・緯度4以上です。二次要素では曲面上の中間幾何節点も生成します。メッシュ図と「節点」「要素」を確認してから解析します。接合面は両側の幾何節点・中間節点・場節点が一致する分割にしてください。

## 境界条件の種類と符号

各方向で`u`は既知変位[m]、`t`は既知表面力[kPa]です。変位を指定すれば対応する表面力が未知、表面力を指定すれば対応する変位が未知となります。成分は全体座標のX/Y/Z方向です。

`ALL`を領域全体の既定値とし、個別の境界名の指定を優先します。たとえば全体をtx=ty=0とし、LEFTのXをu=0、BOTTOMのYをu=0、RIGHTのXをt=100とすると、初期モデルの拘束・引張条件になります。同じ領域＋境界名の行を重複させません。

表面力は`t=σn`（nは領域の外向き法線）です。正の内圧pを与える場合は`t=−p n`となり、BOXのXMINではtx=+p、XMAXではtx=−pです。これは圧力そのものを入力する欄ではなく、方向ごとの表面力を入力する表です。

領域全体の剛体移動を抑える変位条件が必要です。表面力だけの問題を剛体モード付きのまま求解する機能はありません。接合面には「接合」の完全接合条件を使用し、同じ面へ外部境界条件を指定しません。界面では変位が連続し、両領域の外向き法線に対応する表面力が釣り合います。

## 解析と保存

B13で`dense` / `fmm` / `auto`を指定します。小さいモデルの確認にはdense、大きいモデルにはFMM、領域ごとの時間・メモリ見積りで選ぶ場合はautoです。FMMではB58=`gmres`を使用します。denseではGMRESまたはLUを選べます。[全設定表](../outputs/bem_vba_stage3/FMM・操作説明.md#解析設定)を参照してください。

「VBA解析実行」は変更した入力からメッシュを再生成します。「収束OK」または未達の表示、D35の真の残差、D49の反復数、内点の「値取得可否」を確認します。入力を変更した後の画面上の旧結果は再解析前の値です。

出力先はB10・B12で設定します。保存先フォルダが利用可能であることを確認してください。解析済みならJSON、CSV、VTK、NPZ、report.jsonを出力し、未解析ならモデルとメッシュを出力します。既存結果は`previous_results_日時/`へ退避します。

「結果CSV取込」は現在のExcel入力に対応する結果を読み込みます。モデルJSONをExcel入力表へ読み込む機能とは異なります。VTKは可視化用、NPZはNumPy互換の配列保存用です。VTKでは不連続場を保持するため、共有幾何節点を要素ごとに複製しています。
