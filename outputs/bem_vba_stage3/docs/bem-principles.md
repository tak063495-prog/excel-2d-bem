# このブックのBEMの原理

## 境界だけを分割して内部の弾性場を求める

境界要素法（BEM）は、材料内部の支配方程式を満たす基本解を用いて、変位uと表面力tの関係を境界上の積分方程式として表します。この実装では線形・等方・静的弾性、体積力なしを対象とします。領域ごとにEとνが一定で、材料が変わる界面も境界として分割します。

ひずみ、応力、外向き表面力は次の関係です。

```text
ε = (∇u + ∇uᵀ) / 2
σ = λ tr(ε) I + 2μ ε
t = σ n
∇·σ = 0
μ = E / [2(1+ν)]
λ = Eν / [(1+ν)(1−2ν)]   （3D・平面ひずみ）
```

Uは集中単位力によるKelvin変位基本解、Tはそれに対応する表面力基本解です。境界Γ上の値を使うSomiglianaの表現は、領域内部の点xでは次の形になります。

```text
u(x) = ∫Γ U(x,y) t(y) dΓ − ∫Γ T(x,y) u(y) dΓ
```

xを境界へ近付けると、自由項Cと主値積分を含む境界式になります。滑らかな境界ではC=I/2です。

```text
C(x)u(x) + PV∫Γ T(x,y)u(y)dΓ = ∫Γ U(x,y)t(y)dΓ
```

これが境界変位と表面力から変形・応力を計算する出発点です。特異積分の一般的な背景は[Overdijk (1994), Boundary element algorithms for Somigliana's identity](https://research.tue.nl/en/publications/boundary-element-algorithms-for-somiglianas-identity/)を参照してください。本ブックの離散化・積分方法は以下の実装に対応します。

## 要素と未知数

2Dは線要素、3Dは三角形要素で境界を分割します。幾何の節点と、変位・表面力を評価する場節点は別です。

| 次数 | 2Dの幾何／場節点数・要素 | 3Dの幾何／場節点数・要素 |
|---|---|---|
| 0 | 2節点線／中央1点 | 3節点三角形／重心1点 |
| 2 | 3節点線／内部3点 | 6節点三角形／内部6点 |

二次の場節点は要素内側に配置します。隣の要素と場節点を共有せず、角部や境界条件の切替で異なる表面力を表現します。このため幾何節点数と未知数は一致しません。単一領域では、通常は場節点数×次元が境界未知数です。接合では界面の未知数を共有するため、モデル全体の数え方が変わります。

境界積分を離散化すると次の形です。

```text
H u − G t = 0
```

GはUの積分、HはTの積分と自由項を含みます。各成分で既知のuまたはtを右辺へ移し、未知の成分を並べて`A z = b`を解きます。実装は剛体並進で表面力が0となる恒等式を使い、Hの対角ブロックを行和で補正します。単に全対角へ0.5を足す処理としては実装していません。

完全接合の界面では、両側の変位が一致し、外向き表面力の和が0となるよう未知数を対応付けます。

```text
uA = uB
tA + tB = 0
```

## 2Dの平面状態

plane_strainはεzz=0です。面内の応力があるとσzzは一般に0ではなく、本ブックは内点結果へσzzも出力します。plane_stressはσzz=0です。面内の基本解には実効ポアソン比`ν/(1+ν)`を使い、せん断弾性係数μは元のE・νから計算します。plane_stressの面内λは`Eν/(1−ν²)`です。3Dでは元のE・νを使用します。対応処理は[BEM_Solver](../vba_utf8/BEM_Solver.bas)と[BEM_Fields](../vba_utf8/BEM_Fields.bas)にあります。

## 特異積分と内部応力

通常の境界要素はGauss積分を使います。評価点が同じ要素にある自己項は、2Dでは評価点の両側に分けたDE（二重指数）積分、3Dでは評価点を中心とした三角形の分割・半径方向と角方向の積分を使います。零距離の基本解を通常のGauss点で評価する方法ではありません。[BEM_Numerics](../vba_utf8/BEM_Numerics.bas)

境界を解いた後、内部変位は同じ積分表現、内部応力は基本解の微分と構成式から求めます。境界に近い内点では積分が急変するため、最近接位置を求め、Gauss／DEの精細化を切り替えながら誤差を推定します。推定値は厳密な誤差上界ではありません。[BEM_Closest](../vba_utf8/BEM_Closest.bas)、[BEM_Fields](../vba_utf8/BEM_Fields.bas)

issue #1修正後は、コロケーション点・要素幾何・積分点を同じ局所座標で計算します。基本解は二点の差に依存するため、領域の平行移動で物理的な演算は変わりません。結果の位置には元の絶対座標を戻します。

## denseとFMM

denseはG/Hを保存して行列積を計算します。未知数が増えると記憶量と行列積の負荷が増えます。FMMは近傍を直接積分し、遠方の相互作用をChebyshev補間でまとめます。2Dは四分木、3Dは八分木で領域内の場節点を分類します。

```text
要素の寄与を葉の展開へ集約
    ↓ 上向き伝達 M2M
遠方の展開を対象側へ変換 M2L
    ↓ 下向き伝達 L2L
対象点で評価 ＋ 近傍ブロックの直接作用
```

一般的な補間型FMMの遠方近似は`K(x,y) ≈ ΣαΣβ Lα(x) K(ξα,ηβ) Lβ(y)`と表され、基本解の評価値と補間基底から作用を組み立てます。[Fong & Darve (2009), The black-box fast multipole method](https://mc.stanford.edu/cgi-bin/images/f/fa/Darve_bbfmm_2009.pdf)

このVBA実装は添付元PythonのChebyshev・木・M2M/M2L/L2L・近傍ブロックを移植しています。M2Lには容量制限付きLRUキャッシュを使用します。参考論文のSVDによるM2L圧縮は本実装にはありません。VBAのJacobi SVDはGMRESのブロック前処理の擬似逆に使用します。[CFmmOperator](../vba_utf8/CFmmOperator.cls)、[CChebyshev](../vba_utf8/CChebyshev.cls)

FMMは要素や自由度を減らす機能ではなく、同じ離散問題の行列作用を近似して計算する機能です。p、leaf、theta、形状とメッシュ分布により負荷・精度が変わります。

## GMRESと残差

再始動GMRESは、行列作用とブロック前処理を用いて未知境界値を反復更新します。FMMでは全体の密行列を作らずに反復します。denseではLUも使えます。[BEM_Linear](../vba_utf8/BEM_Linear.bas)

通常の真の相対残差は`||H u − G t||₂ / ||b||₂`です。bが丸め誤差程度になる場合は演算項の尺度で正規化し、ゼロ荷重・ゼロ変位の解は残差0とします。判定方法はreport.jsonにも記録します。

小さい残差は離散方程式をよく満たすことを示します。材料差などによる条件の悪さ、FMM近似、メッシュ誤差まで含めた解の精度は、[注意事項の比較手順](limitations.md#収束okで確認される範囲)で確認してください。
